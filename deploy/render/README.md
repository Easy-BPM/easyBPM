# Render Deployment

This Render Blueprint starts all runtime pieces:

- `easybpm-web`: nginx, all three frontends, and the Spring Boot API
- `easybpm-worker`: the background worker jar
- `easybpm-rabbitmq`: private RabbitMQ service used by the API and worker

The public web routes are:

- `/` redirects to `/ui/modeler/`
- `/ui/modeler/`
- `/ui/admin/`
- `/ui/portal/`
- `/modeler/`, `/admin`, and `/portal/` redirect to their `/ui/...` routes

API routes remain at the root, such as `/auth`, `/processes`, `/tasks`, `/forms`, `/api/documents`, and `/actuator/health`.

## Required Secrets

When Render asks for `DATABASE_URL`, paste the Neon connection string from the Neon dashboard. Keep it in Render only; do not commit it to Git.

The startup scripts accept either:

- `postgresql://...`
- `postgres://...`
- `jdbc:postgresql://...`

They convert Neon-style URLs to Spring's JDBC format and mirror the same database settings into the worker.

Render will also prompt for:

- `EASY_BPM_SERVER_SECURITY_BOOTSTRAP_ADMIN_PASSWORD`

`EASY_BPM_SERVER_SECURITY_JWT_SECRET` and the RabbitMQ password are generated by Render.
