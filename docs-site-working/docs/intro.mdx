# Welcome to Easy BPM

**Easy BPM** is a modern, production-ready Business Process Management (BPM) engine built with Spring Boot and Kotlin.

## What is Easy BPM?

Easy BPM is a lightweight yet powerful orchestration platform that enables you to:

✅ **Deploy** BPMN-style process definitions  
✅ **Execute** processes at scale with automatic state management  
✅ **Integrate** with external systems via HTTP and messaging  
✅ **Monitor** process execution with metrics and health checks  
✅ **Scale** horizontally with stateless microservices  

## Key Features

🚀 **Process Orchestration**: Define, deploy, and execute business processes  
👥 **Task Management**: Create human tasks, assign to users, collect data via forms  
🔄 **Event-Driven**: Send/receive messages to trigger and advance processes  
🍎 **Worker Architecture**: Async service execution with retry logic and idempotency  
📊 **Observability**: Built-in metrics, health checks, Prometheus integration  
🏗️ **Cloud-Native**: Stateless services, horizontal scaling, Docker-ready  

## Technology Stack

- **Framework**: Spring Boot 3.5.3
- **Language**: Kotlin
- **Database**: PostgreSQL (with Flyway migrations)
- **Messaging**: RabbitMQ (AMQP)
- **Monitoring**: Micrometer + Prometheus
- **API**: REST with OpenAPI/Swagger

## Quick Start

Get up and running in 5 minutes:

```bash
# Start infrastructure
docker-compose up -d

# Start BPM engine
./gradlew bootRun

# Server running at http://localhost:8080
# API docs at http://localhost:8080/swagger-ui.html
```

Deploy your first process:

```bash
curl -X POST http://localhost:8080/processes \
  -H "Content-Type: application/json" \
  -d '{
    "nodes": [
      {"id": "start", "type": "StartEvent"},
      {"id": "task1", "type": "UserTask", "name": "Review"},
      {"id": "end", "type": "EndEvent"}
    ],
    "edges": [
      {"source": "start", "target": "task1"},
      {"source": "task1", "target": "end"}
    ]
  }'
```

See [Getting Started](./getting-started.md) for detailed setup instructions.

## Getting Started

Get started by **creating a new site**.

Or **try Docusaurus immediately** with **[docusaurus.new](https://docusaurus.new)**.

### What you'll need

- [Node.js](https://nodejs.org/en/download/) version 20.0 or above:
  - When installing Node.js, you are recommended to check all checkboxes related to dependencies.

## Generate a new site

Generate a new Docusaurus site using the **classic template**.

The classic template will automatically be added to your project after you run the command:

```bash
npm init docusaurus@latest my-website classic
```

You can type this command into Command Prompt, Powershell, Terminal, or any other integrated terminal of your code editor.

The command also installs all necessary dependencies you need to run Docusaurus.

## Start your site

Run the development server:

```bash
cd my-website
npm run start
```

The `cd` command changes the directory you're working with. In order to work with your newly created Docusaurus site, you'll need to navigate the terminal there.

The `npm run start` command builds your website locally and serves it through a development server, ready for you to view at http://localhost:3000/.

Open `docs/intro.md` (this page) and edit some lines: the site **reloads automatically** and displays your changes.
